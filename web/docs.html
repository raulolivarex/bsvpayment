Quick Start

Get started with ROXEXPay in 3 steps. Accept payments with a single API call.

1. Get your API keys

Create a free account at dashboard.roxexpay.io. Your API keys are generated instantly — no approval process, no KYC delays.

2. Create a payment

curl 
curl -X POST https://api.roxexpay.io/v1/payments \
  -H "Authorization: Bearer sk_live_your_key" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 2500,
    "currency": "EUR",
    "description": "Premium plan"
  }'

3. Redirect to checkout

Use the checkout_url from the response to send your customer to our hosted checkout page. They pay with card — Settlement happens instantly under the hood.

response 
{
  "id": "pay_a1b2c3d4e5f6",
  "amount": 2500,
  "currency": "EUR",
  "status": "pending",
  "fee": 25,
  "net": 2475,
  "checkout_url": "https://pay.roxexpay.io/checkout/pay_a1b2c3d4e5f6"
}
That's it. When the customer pays, you receive the funds instantly. No 2-day hold, no rolling payouts.

Authentication

All API requests require authentication via a Bearer token in the Authorization header.

Authorization: Bearer sk_live_your_secret_key

You have two types of keys:

  • Secret key (sk_live_...) — Use server-side only. Required for creating payments, refunds, and reading balance.
  • Public key (pk_live_...) — Safe for client-side. Used for the checkout widget.
Never expose your secret key in client-side code, GitHub repos, or logs.

Create Payment

POST /v1/payments

Creates a new payment and returns a checkout URL.

Parameters

ParameterTypeRequiredDescription
amount integer required Amount in cents (e.g., 1050 = $10.50)
currency string required EUR or USD
description string optional Description shown to customer on checkout
metadata object optional Key-value pairs for your reference

Response

{
  "id": "pay_a1b2c3d4e5f6",
  "amount": 1050,
  "currency": "EUR",
  "status": "pending",
  "fee": 11,
  "net": 1039,
  "description": "Order #1234",
  "checkout_url": "https://pay.roxexpay.io/checkout/pay_a1b2c3d4e5f6",
  "created": "2026-01-15T10:30:00Z"
}

Confirm Payment

POST /v1/payments/:id/confirm

Confirms a pending payment. This is called automatically when the customer completes the hosted checkout. You can also call it directly for server-to-server integrations.

The payment is settled instantly through our proprietary network. The customer never sees the underlying technology.

Create Refund

POST /v1/refunds

Refunds a succeeded payment. Full or partial.

Parameters

ParameterTypeRequiredDescription
payment_id string required ID of the payment to refund
amount integer optional Amount in cents. Omit for full refund.
curl 
curl -X POST https://api.roxexpay.io/v1/refunds \
  -H "Authorization: Bearer sk_live_your_key" \
  -d '{"payment_id": "pay_a1b2c3d4e5f6"}'

Hosted Checkout

ROXEXPay provides a beautiful, conversion-optimized hosted checkout page. Just redirect your customer to the checkout_url from the payment response.

html 
<!-- Redirect after creating a payment -->
<a href="https://pay.roxexpay.io/checkout/pay_a1b2c3d4e5f6">
  Pay now
</a>

<!-- Or redirect via JavaScript -->
window.location.href = response.checkout_url;

The checkout page handles card input, payment processing, and success/error states. After payment, the customer is redirected to your success URL.

Error Handling

ROXEXPay uses standard HTTP status codes. All errors return a JSON body with error and message fields.

CodeMeaning
200Success
400Bad request — invalid parameters
401Unauthorized — missing or invalid API key
404Not found — payment does not exist
500Server error
error 
{
  "error": "invalid_amount",
  "message": "Amount must be a positive integer (in cents)"
}

SDKs

Official SDKs coming soon. For now, ROXEXPay works great with cURL, fetch, or any HTTP client.

JavaScript

js 
const response = await fetch('https://api.roxexpay.io/v1/payments', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer sk_live_your_key',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    amount: 2500,
    currency: 'EUR',
    description: 'Premium plan'
  })
});
const payment = await response.json();
window.location.href = payment.checkout_url;

Python

python 
import requests

response = requests.post(
    "https://api.roxexpay.io/v1/payments",
    headers={"Authorization": "Bearer sk_live_your_key"},
    json={
        "amount": 2500,
        "currency": "EUR",
        "description": "Premium plan"
    }
)
payment = response.json()
print(payment["checkout_url"])
